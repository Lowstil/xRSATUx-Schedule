# 🎓 xRSATUx Schedule (Расписание РГАТУ им. П. А. Соловьёва)

[![Platform](https://img.shields.io/badge/Android-8.0%2B%20(API%2026--36)-3DDC84?logo=android&logoColor=white)](https://developer.android.com)
[![Language](https://img.shields.io/badge/Java-17-ED8B00?logo=openjdk&logoColor=white)](https://openjdk.org)
[![UI](https://img.shields.io/badge/UI-Liquid%20Glass-6C8CFF)](https://github.com/Lowstil/xRSATUx-Schedule)
[![Offline](https://img.shields.io/badge/Mode-Offline--First%20SQLite-059669)](https://github.com/Lowstil/xRSATUx-Schedule)

Современное, быстрое и визуально выразительное Android-приложение для просмотра расписания занятий студентов и преподавателей **Рыбинского государственного авиационного технического университета имени П. А. Соловьёва (РГАТУ им. П. А. Соловьёва)**.

Приложение автоматически загружает актуальные таблицы расписания и журнал переносов с официального сайта вуза (`rsatu.ru`), сохраняет их в локальную базу данных SQLite и полноценно работает без интернета.

---

## ✨ Дизайн-система Liquid Glass

Интерфейс выполнен в стиле **Liquid Glass** (вдохновлён iOS):
- **Живой Edge-to-Edge Mesh-фон (`AmbientBackdropView`):** полноэкранный анимированный градиент с 2% микрозерном (`AGSL RuntimeShader` на Android 13+ и плавный `RadialGradient` на Android 8–12), который мягко реагирует на активную пару.
- **Многослойное матовое стекло (`GlassSurfaceHelper`):**
  - Полупрозрачные карточки (`22dp`) и плавающие капсулы с **1dp спекулярной (бликовой) обводкой под углом 135°**.
  - **Android 12+ (API 31+):** нативное размытие фона позади диалогов (`windowBackgroundBlurRadius` / `blurBehindRadius`).
  - **Android 8–11 (API 26–30):** оптимизированный матовый fallback без нагрузки на CPU.
- **Светлая и тёмная темы + режим доступности:** сбалансированная светлая палитра с высокой контрастностью, глубокая ночная тема и настройка **«Уменьшить прозрачность»** (учитывается системный режим энергосбережения).
- **Парящий нижний док (Floating Liquid Glass Bottom Dock):** компактная стеклянная панель быстрого доступа внизу экрана (Поиск аудиторий/преподавателей, Звонки, Хаб домашек, Посещаемость, Настройки).
- **Эффектная подсветка пар:**
  - Текущая пара выделяется изумрудно-индиговым свечением, градиентной рамкой и пульсирующей капсулой **`LIVE`**.
  - Следующая пара подсвечивается небесно-синим стеклом, мягким ореолом и бейджем **`ДАЛЕЕ`**.

## 🚀 Основные возможности

### 1. 📅 Умная навигация и расписание (`ViewPager2`)
- **Горизонтальные свайпы дней:** плавное перелистывание между днями недели (ПН–СБ) свайпом влево/вправо, синхронизированное с парящими стеклянными вкладками.
- **Логичное переключение недель:** стрелки `<` и `>` всегда открывают **понедельник** выбранной недели.
- **Умный старт в воскресенье:** в воскресенье (когда занятий нет) приложение автоматически открывает **понедельник следующей недели (завтра)**.
- **Быстрый возврат «к сегодня»:** нажатие на плашку с датой в верхнем тулбаре мгновенно возвращает к актуальному дню.
- **Двухнедельный цикл и умные бейджи:** автоматический расчёт номера недели семестра, чётности (чётная / нечётная) и цветные пометки *«Сегодня»*, *«Завтра»*, *«Наступит через N дн.»*.

### 2. ☕ Умный детектор «Окон» между парами
- Если между активными парами есть свободный слот (например, после 1-й пары сразу 3-я), в списке автоматически появляется полупрозрачная стеклянная карточка с точным временем и длительностью перерыва (например, *«☕ Окно · 2 ч 35 мин»*).

### 3. ⏱ Трёхсегментный таймер пары (45-5-45) и живое уведомление
- **Внутри карточки и на виджете:**
  - 🟢 **0–45 мин:** первая половина пары.
  - 🟠 **45–50 мин:** 5-минутный перерыв в середине пары.
  - 🟢 **50–95 мин:** вторая половина пары.
- **Живой таймер в шторке и на экране блокировки (`LiveLessonService`):** постоянное уведомление с текущим этапом (45м / перерыв / 45м), прогресс-баром, аудиторией и следующей парой. При желании **отключается тумблером в настройках**.

### 4. 📊 Трекер посещаемости и бюджет пропусков
- **Отметка по долгому нажатию:** зажатие любой карточки пары открывает компактное стеклянное окно с выбором:
  - 🟢 **«Посетил / Пойду»** — отметка посещения (работает и для прошедших, и заранее для будущих пар).
  - 🔴 **«Н-ка (Пропуск)»** — отметка пропуска (карточка перечёркивается, а напоминания перед этой парой отключаются).
  - ⚪ **«Сбросить отметку»** — возврат стандартного статуса.
- **Обновлённое окно «Моя посещаемость»:**
  - Кастомные круговые кольца прогресса (`CircularProgressRingView`) для общего процента и каждого предмета.
  - **Настраиваемый лимит пропусков (`20%` | `25%` | `30%`)** и понятный бюджет: *«Можно пропустить ещё 2 пары»*, *«Последний запас»* или *«Лимит превышен»*.
  - Ручная корректировка счётчика Н-ок (`+` / `−`).
- **Перезачёт предметов с поиском:** в настройках можно вычеркнуть любые предметы текущей группы (например, при перезачёте) с удобным поиском по списку.

### 5. 🔍 Поиск свободных аудиторий и преподавателей (офлайн)
- Встроенный инструмент в меню и настройках работает полностью без интернета по локальной базе всех групп и преподавателей:
  - **«Где преподаватель?»:** быстрый поиск преподавателя показывает, в какой аудитории он находится прямо сейчас и все его пары на день.
  - **«Свободные аудитории»:** выбор корпуса (*Главный, Первый, Второй, Третий, Точка кипения*) и номера пары выводит список свободных в этот момент кабинетов.

### 6. 🔄 Подсветка изменений после обновления (`Что изменилось?`)
- При синхронизации расписания приложение сравнивает новые данные с предыдущим локальным снимком (`ScheduleDiff`), фиксирует добавленные/отменённые пары, смены аудиторий и преподавателей, и выводит наглядную сводку изменений.

### 7. 📤 Экспорт и «Поделиться расписанием»
- В настройках доступен экспорт расписания **дня или всей недели**:
  - 🖼️ **Красивой Liquid Glass картинкой** (рендерится локально на `Canvas` и передаётся через `FileProvider`).
  - 📝 **Отформатированным текстом** для быстрой отправки одногруппникам в Telegram / VK.

### 8. ⭐ «Избранное» с удалением по зажатию
- Сохраняйте нужные группы и преподавателей звёздочкой (⭐) для переключения в один тап на главном экране.
- **Удаление по долгому нажатию:** зажмите чип в панели избранного, чтобы удалить его через окно подтверждения.

### 9. 📝 Заметки к парам, хаб домашек и интерактивные карточки
- **Заметки и фото:** нажатие на карточку пары открывает окно заметок и домашних заданий с чекбоксом выполнения и возможностью прикрепить фото (конспекта, доски, методички) с полноэкранным просмотром и зумом.
- **Хаб домашних заданий (`HomeworkHubDialog`):** единый центр всех заметок и домашек с фильтрацией, отметкой выполнения и быстрым переходом к нужному дню.
- **Интерактивные преподаватели и корпуса (`BuildingInfoDialog`):** нажатие на имя преподавателя открывает его расписание, а тап по корпусу/аудитории показывает карточку корпуса с адресом и ориентирами.

### 10. 📱 Виджеты на рабочий стол (Faux-Liquid Glass)
- **Компактный мини-виджет 2×1:** текущая пара, аудитория и живой 3-сегментный прогресс-бар `45-5-45` (или таймер до следующей пары).
- **Полноразмерный виджет 4×2:** список занятий на сегодня, автоматическое переключение на превью **«Завтра»** после окончания пар и кнопка ручного обновления **`↻`**.

### 11. 🔔 Уведомления, переносы и справочник звонков
- Напоминания за 10 / 15 / 30 минут до начала пары, утренний дайджест в `07:30`, уведомления о переносах/заменах и автовосстановление будильников после перезагрузки (`BootReceiver`).
- Парсинг журнала переносов и замен вуза (отмены, переносы, смены аудиторий).
- Интерактивное расписание звонков (для ПН–ПТ с большой переменой 50 мин и для СБ) с подсветкой текущего слота.

### 12. 📌 Личные события и пользовательские пары (`CustomEventDialog`)
- Добавление собственных событий (репетитор, секция, консультация, дедлайн) в любой день недели и пару/слот времени с выбором повторения (разовое, еженедельно, чётная/нечётная неделя) и цветовой метки.
- Личные события органично отображаются в общем списке дня наравне с университетскими парами.

### 13. 🤝 Сравнение расписания с другой группой «Общие окна» (`CompareScheduleDialog`)
- Выбор любой второй группы или преподавателя для наложения расписаний на выбранный день или неделю.
- Автоматический подсчёт и подсветка **общих свободных окон**, когда обе группы не заняты, чтобы легко договориться о встрече или совместной подготовке.

### 14. 🌸🍂 Два семестра в единой ленте и автопереход (`SemesterManager`)
- **Единая 36-недельная лента:** Осень (недели 1–18) и Весна (недели 1–18), всего **216 страниц** в `ViewPager2`. Бесшовное переключение между семестрами свайпом и кнопками `<` / `>` сопровождается всплывающей стеклянной плашкой (`🌸 Весенний семестр` / `🍂 Осенний семестр`).
- **Раздельное хранение в SQLite:** `DatabaseHelper` v6 хранит осеннее и весеннее расписания раздельно по `semester_id`.
- **Автопереход и проверка публикации:** автоматический переход после **30 января** (весна) и **25 августа** (осень) по SHA-256 хэшу файла с `rsatu.ru`, а также заглушка неопубликованного семестра с кнопкой **«Проверить сейчас»**.

> **Обновление 3.3:** единая 36-недельная лента двух семестров, раздельное хранение в SQLite (`DatabaseHelper` v6), автопереход по SHA-256 и заглушка неопубликованного семестра.

## 🛠 Стек технологий и архитектура

* **Язык:** Java 17
* **Платформа:** Android (`minSdk 26`, `targetSdk 36`, `compileSdk 36`)
* **Слои проекта:**
  * `ui/glass` — дизайн-система Liquid Glass (`AmbientBackdropView`, `GlassSurfaceHelper`)
  * `ui/view` — кастомные компоненты (`CircularProgressRingView`)
  * `ui/controller` — контроллеры состояния экрана (`WeekScheduleController`)
  * `ui/activity`, `ui/adapter`, `ui/dialog` — экраны, `ViewPager2`-адаптер, карточки, диалоги (`HomeworkHubDialog`, `BuildingInfoDialog`, `CustomEventDialog`, `CompareScheduleDialog` и др.)
  * `data/db` — локальная SQLite БД (`DatabaseHelper` v6 с `semester_id`, `ScheduleDao`, `TransferDao`, `NoteDao`, `CustomEventDao`, `HolidayDao`, `UserDao`)
  * `data` — сетевой клиент с trust-конфигурацией для `rsatu.ru`, парсеры `.xlsx` и переносов, `ScheduleRepository`
  * `logic` — управление семестрами (`SemesterManager`), расчёт недель (`WeekCalculator`), фильтрация и сортировка (`ScheduleFilter`), праздники (`HolidayChecker`)
  * `model` — модели расписания, заметок, переносов и `ScheduleDiff`
  * `notification` — `LiveLessonService`, `ReminderScheduler`, `ReminderReceiver`, `MorningDigestReceiver`, `BootReceiver`
  * `widget` — `CompactScheduleWidgetProvider`, `TodayScheduleWidgetProvider`, `ScheduleWidgetService`, `ScheduleWidgetFactory`
  * `util` — `AttendanceManager`, `ScheduleClock`, `ScheduleExporter`, `DateUtils`, `RoomFormatter`, `EdgeToEdgeCompat`, `PrefsManager`
* **Библиотеки:**
  * `com.google.android.material:material:1.11.0`
  * `androidx.appcompat:appcompat:1.6.1`
  * `androidx.viewpager2:viewpager2:1.0.0`
  * `androidx.recyclerview:recyclerview:1.3.2`
  * `androidx.swiperefreshlayout:swiperefreshlayout:1.1.0`
  * `org.apache.poi:poi-ooxml:5.2.5` — потоковый парсинг `.xlsx` файлов расписания
  * `com.squareup.okhttp3:okhttp:4.12.0` — сетевая загрузка файлов
  * `junit:junit:4.13.2` — 66+ unit-тестов логики семестров (`SemesterManagerTest`), времени, фильтрации, парсинга и бюджета пропусков

## 🔨 Сборка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Lowstil/xRSATUx-Schedule.git
   cd xRSATUx-Schedule
   ```
2. Откройте проект в **Android Studio**.
3. Убедитесь, что в качестве Gradle JDK выбран **Java 17** (или встроенный JBR Android Studio).
4. Соберите отладочный APK:
   ```bash
   ./gradlew assembleDebug
   ```
5. Готовый APK будет находиться в `app/build/outputs/apk/debug/app-debug.apk`.
