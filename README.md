# 🎓 UniSchedule (Расписание РГАТУ им. П. А. Соловьёва)

Современное, быстрое и удобное Android-приложение для просмотра расписания занятий студентов и преподавателей **Рыбинского государственного авиационного технического университета имени П. А. Соловьёва (РГАТУ им. П. А. Соловьёва)**.

Приложение автоматически загружает и парсит актуальные таблицы расписания и журнал переносов с официального сайта вуза, сохраняет их в локальную базу данных SQLite и полноценно работает в оффлайн-режиме.

---

## 🚀 Основные возможности

### 1. 📅 Расписание для студентов и преподавателей
- **Выбор группы или преподавателя:** мгновенный поиск по номеру группы или фамилии преподавателя.
- **Двухнедельный цикл:** автоматический расчёт номера недели семестра и определение чётности недели (чётная / нечётная).
- **Навигация по дням и неделям:** переключение недель стрелками и быстрый выбор дней недели (ПН–СБ).
- **Умные бейджи на днях:** вкладки дней отображают число месяца, общее название месяца (например, *«Октябрь»* или *«Октябрь – Ноябрь»*) и индивидуальные разноцветные подсветки:
  - 🔵 **«Сегодня»** — выделенная плашка с текущим днём.
  - 🟠 **«Завтра»** — тёплая янтарная пометка.
  - 🟣 **«Наступит через X дня(ей)»** — автоматический расчёт дней до занятия с правильным склонением.

### 2. ⏱ Трёхсегментный живой таймер пары (45-5-45)
- Наглядный студенческий таймер с учётом перемены в середине пары:
  - 🟢 **0–45 мин:** первая половина пары.
  - 🟠 **45–50 мин:** 5-минутный перерыв в середине пары.
  - 🟢 **50–95 мин:** вторая половина пары.
- Во время перемены карточка информирует об обратном отсчёте: *«Следующая · перемена (до пары 10 мин)»*.

### 3. 📊 Учёт посещаемости и гибкая система «Н-ок» (пропусков)
- **Отметка в 1 тап по долгому нажатию:** при зажатии карточки пары открывается модальное окно с выбором:
  - 🟢 **«Посетил / Пойду»** — отметить посещение занятия (работает как для прошедших, так и заранее для будущих пар).
  - 🔴 **«Н-ка (Пропуск)»** — отметить пропуск; карточка перечёркивается, а лишние напоминания перед парой автоматически отключаются.
  - ⚪ **«Сбросить отметку»** — возвращение стандартного вида занятия.
- **Окно «Моя посещаемость»:**
  - Плотное затемнение заднего фона диалога (70% scrim) исключает наслоение текста.
  - Сводный процент посещаемости и детальная статистика по каждому предмету.
  - Предупреждающий бейдж при $\ge 3$ пропусках (*«🟡 Внимание: уже 3 Н-ки, пора ходить!»*).
  - Кнопки быстрой ручной корректировки энок (`+` / `−`).

### 4. ⭐ «Избранное» и быстрое переключение в 1 тап
- Добавление любых групп и преподавателей в закладки с помощью звёздочки (⭐).
- Горизонтальная панель быстрого доступа на главном экране: переключение между своей группой и расписанием нужных преподавателей/друзей в один клик без сброса настроек.
- Отдельная вкладка *«⭐ Избранное»* на экране выбора.

### 5. 📝 Домашние задания и заметки с фотографиями
- При нажатии на любую пару открывается диалог для записи задач (*«Сдать лабораторную №2», «Принести методичку»*).
- Прикрепление фотографий (доски, методички, конспекты) прямо к карточке пары с полноэкранным зумом.
- На карточке пары отображается бейдж с текстом задачи и индикатором фото.

### 6. 📱 Виджеты на рабочий стол
- **Компактный мини-виджет 2×1:** номер пары, аудитория, статус и живой таймер (45-5-45) либо крупный отсчёт перемены.
- **Полноразмерный виджет 4×2:** подробный список занятий на весь день.

### 7. 🔔 Умные уведомления и напоминания
- **Напоминание перед началом пары:** настраиваемое уведомление за 10, 15 или 30 минут до звонка с указанием предмета, типа пары и аудитории.
- **Утренний дайджест в 07:30:** сводное утреннее уведомление на экране блокировки с количеством пар на сегодня, временем начала первой пары и временем окончания занятий.
- **Оповещения об изменениях:** при фоновом обновлении и обнаружении переносов или замен занятий приложение отправляет предупреждение.
- **Восстановление после перезагрузки:** автоматический перезапуск будильников через `BootReceiver`.

### 8. 🔄 Журнал переносов и замен занятий
- Полная интеграция с файлом переносов вуза: поддержка различных форматов дат (ISO, `dd.MM.yyyy`, числовые даты Excel).
- Отменённые занятия перечёркиваются в расписании.
- Перенесённые занятия и замены аудиторий помечаются специальным бейджем *«Перенесено / Замена аудитории»*.

### 9. 🔔 Интерактивный справочник звонков
- Удобная таблица звонков пар и перемен с разделением на:
  - **Будни (ПН–ПТ):** включая большую перемену 50 минут (11:50 – 12:40).
  - **Суббота (СБ):** специальное расписание звонков выходного дня.
- Подсветка текущей пары прямо внутри таблицы звонков.

### 10. 🌓 Тёмная и светлая темы оформления
- Полноценная поддержка Material Components DayNight.
- Выбор темы в настройках: **Системная** (по умолчанию), **Светлая**, **Тёмная**.
- Скругление карточек 18dp и контрастная палитра для ночного режима.

### 11. ⚡ Оффлайн-работа и надёжная синхронизация
- Все данные сохраняются в локальную SQLite базу данных.
- Поддержка кастомного TrustManager для надёжного соединения с официальным сайтом РГАТУ (`rsatu.ru`).
- Фоновая проверка свежести расписания и мягкое автообновление раз в сутки.

## 🛠 Стек технологий

* **Язык программирования:** Java 17
* **Платформа:** Android (minSdk 26, targetSdk 36, compileSdk 36)
* **Архитектурный подход:** Single-Activity / Multi-Screen с DAO-репозиторием и чистым разделением слоёв:
  * `ui/activity`, `ui/adapter`, `ui/dialog` — пользовательский интерфейс
  * `data/db` — локальная база данных SQLite (DAO, Contract, OpenHelper)
  * `data` — сетевой клиент, парсеры расписания и переносов
  * `logic` — расчёт чётности/нечётности недель, календарь семестра, праздники
  * `notification` — планировщик напоминаний, ресиверы и каналы уведомлений
  * `widget` — AppWidgetProvider и RemoteViewsService
* **Библиотеки:**
  * `com.google.android.material:material:1.11.0` — Material 3/DayNight компоненты
  * `androidx.appcompat:appcompat:1.6.1`
  * `androidx.recyclerview:recyclerview:1.3.2`
  * `androidx.swiperefreshlayout:swiperefreshlayout:1.1.0`
  * `org.apache.poi:poi-ooxml:5.2.5` — потоковый парсинг Excel (.xlsx) файлов расписания
  * `com.squareup.okhttp3:okhttp:4.12.0` — надёжная загрузка файлов по сети
  * `junit:junit:4.13.2` — модульное тестирование логики времени и парсинга

## 🔨 Сборка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Lowstil/xRSATUx-Schedule.git
   cd xRSATUx-Schedule
   ```
2. Откройте проект в **Android Studio**.
3. Убедитесь, что в качестве Gradle JDK выбран **Java 17 или Java 21**.
4. Запустите сборку:
   ```bash
   ./gradlew assembleDebug
   ```
5. Сгенерированный APK будет находиться в папке `app/build/outputs/apk/debug/app-debug.apk`.
